## About Me

I'm an **Information Technology Education** student who decided to go deeper into **cyber security**, with the long-term goal of becoming a **red teamer / ethical hacker**.

My program doesn't include network security courses, so I'm learning it **on my own**, using hands-on labs, documentation, and AI as a study partner. I believe the best way to learn security is to break things in a safe environment and write down what I learn.

## My Journey So Far

- Started with **Linux Mint** to get comfortable with Linux for about 2 weeks, then moved to **Parrot OS** (after trying it via live USB)
- Working through **OverTheWire: Bandit** (SSH and Linux basics), currently around level 6
- Practiced **SQL Injection** in my own private lab
- Hands-on with **Burp Suite** and **Nmap**
- Built local practice environments with **Laragon + MySQL**

## Currently Learning

- Linux command line and privilege basics
- Networking fundamentals
- Web application security (OWASP Top 10)
- Beginner CTF challenges
